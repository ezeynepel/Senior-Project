# ARIS — Smart Military Helmet Project / Senior Project

ARIS is a smart military helmet project developed as part of the CMPE Senior Project.  
The project aims to improve field awareness, personnel safety, and real-time coordination in military operations by combining multimodal recognition, live monitoring, command processing, and a web-based dashboard.

## Project Website

The project website is deployed with GitHub Pages:

[ARIS Project Website](https://ezeynepel.github.io/Senior-Project/)

## Project Overview

ARIS is designed as a smart helmet system for military personnel. The system focuses on collecting and processing field-related information, recognizing commands or signals through different input methods, and presenting the processed data on a centralized dashboard.

The main goal of the project is to support safer and more coordinated field operations by providing real-time information flow between personnel and the command center.

## Key Features

- Smart military helmet system concept
- Real-time field monitoring dashboard
- Gesture recognition pipeline
- Voice command recognition pipeline
- Facial expression recognition pipeline
- Command validation and priority mapping
- Telemetry data display
- Live command feed
- Unit-specific detail view
- Backend API structure for communication
- Project backlog page for progress tracking
- Project document access through the website
