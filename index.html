Project Overview

ARIS is a smart helmet system designed to improve the safety of personnel in military operations. The system integrates face recognition, location tracking, and real-time incident notifications on a centralized platform.

Face Recognition

Verifies personnel identity to support secure access and authorization.

Location Tracking

Displays each unit’s live position on the map for mission coordination.

Event Alerts

Sends alerts and logs to the command center during risky situations.
